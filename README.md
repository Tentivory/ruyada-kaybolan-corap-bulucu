# Rüyada Kaybolan Çorap Bulucu

## Dünyanın En Önemli ve Aynı Zamanda En Gereksiz Projesi

Bu repository, insanlığın en büyük sorunlarından biri olan **rüyalarda kaybolan çoraplar** sorununu çözmek için yaratılmıştır. Bilim adamları yıllardır bu sorunu göz ardı etmiştir. Artık değil.

### Nasıl Çalışır?

1. Programı çalıştırın.
2. Rüyanızda kaybolan çorabınızın rengini ve boyutunu girin.
3. Yapay zeka (aslinda random sayi) size çorabın tam konumunu söyleyecektir: "Sol cebinizin arkasında, 1997 yılının çarşamba gününde."

### Özellikler

- %100 doğruluk oranı (eğer rüya görüyorsanız)
- Gerçek zamanlı rüya analizi
- Çorapların psikolojik durumunu da hesaplar
- Gelecekten gelen çorapları da bulabilir

### Kurulum

```bash
python corap_bulucu.py
```

Hepsi bu. Daha fazlasına gerek yok çünkü bu proje zaten mükemmel.
